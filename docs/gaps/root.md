# 根命题与缺口计数口径

## 当前目标

`LiuWang.TheoremStatement` 定义：每个满足 `Real.exp 3100 ≤ (N : ℝ)` 的奇自然数，是三个奇素数之和（允许重复）。当前源码没有该命题的无条件证明。

## 根层尚缺什么

1. 原文主弧下界及第二、第三弧界的实际分析供给与最终接线。具体未付输入按分线路径列在本目录，不将同一输入在每个消费者上的重复出现重复计数。
2. `FiniteTernaryClosure/Analytic.lean:29–41` 已有实际存在性出口，但它仍要求 `hresidual`：真实主弧相互作用、第二与第三弧积分、显式误差的合计下界。这个总前提不是“小引理”，也不应在所有分项缺口之外再算一个独立分析缺口。
3. 原论文根命题的总装尚未完成。已有旧的更强局部估计不自动证明已经逐式复现原论文。

## 不重复列成缺口的既有组件

- `PrimePowerRemoval/Main.lean` 已经处理实际 von Mangoldt 权污染及仅素数计数正性到奇素数表示。
- `MinorArcEnergy/Ledger.lean:52–78` 已经证明三片次弧共用同一个完整二次能量上界，不能按三片重复支付完整能量。
- `MinorArcEnergy/Fourth.lean:104–115` 的实际第四弧积分界只要求原大数域，没有未付的数论估计参数；它的源码存在不代替恢复后的全依赖重编。
- `FiniteTernaryClosure/Consumer.lean:35–37` 给出9至1000的奇数证书消费者。

## 两种目标必须分开

若要求所有不小于9的奇数，还缺 `1000 < N < exp(3100)` 的衔接；它不计入当前Liu–Wang大数定理的剩余缺口。不能以“有限证书已到1000”声称完成整个小数范围。
